# Shadowrocket 使用指南

适用文件：[shadowrocket-optimized.conf](./shadowrocket-optimized.conf)。更新日期：2026-09-23。

本指南覆盖 Mac 与 iPhone 的分别导入、家庭/外出切换、验证、更新和恢复。功能与参数解释见 [README](./README.md)，家庭路由侧操作见[梅林使用指南](../merlin/使用指南.md)。不同客户端版本的菜单名称可能略有差异。

## 1. 导入前备份

1. 在客户端“配置”中确认当前使用的文件，将其导出或另存到本地，保留原文件与名称。
2. 记录当前节点、全局路由模式及自己添加的私有规则。节点订阅单独管理，本配置不会提供节点或订阅。
3. 下载仓库中的 `.conf` 文件，确认扩展名仍是 `.conf`，而不是 GitHub 网页保存出的 `.html`。

完整路由器 JSON、节点订阅和带私人域名的配置不要上传公开仓库，也不要通过公开分享链接分发。

## 2. Mac 导入与启用

1. 在 Shadowrocket 打开“配置”，使用“导入”或文件导入入口，选择下载的 `shadowrocket-optimized.conf`。
2. 在配置列表中选中该文件并设为使用中的配置；仅导入到列表不等于已启用。检查使用标记或当前配置名称。
3. 回到首页，将“全局路由”设为“配置”，选择需要的现有订阅节点，再打开连接。
4. 在配置详情确认远程规则加载完成，公开文件应包含 43 个远程引用。若仍在下载，等待完成后再测试。
5. 执行下文的基础检查，确认没有误用“全局代理”或另一个旧配置。

不需要为本次导入执行“编译配置”。编译可能展开远程内容，改变后续维护形式；保持可读的远程引用配置更便于更新与排错。

## 3. iPhone 导入与启用

1. 将同一 `.conf` 保存到 iPhone“文件”，或通过私密文件传输方式发送到手机。
2. 在 Shadowrocket 的“配置”页面使用文件导入入口；也可从“文件”的分享菜单发送到 Shadowrocket，以当前版本提供的入口为准。
3. 选中新导入配置使用，回首页将“全局路由”设为“配置”。
4. 选择手机现有订阅中的适用节点，开启连接；若系统首次请求添加 VPN 配置，确认应用与操作来源后按系统提示处理。
5. 确认远程规则加载完成，分别在家庭 Wi-Fi 和外出网络执行基础检查。

Mac 已导入并不表示 iPhone 已导入或自动选中同一配置。两端的连接开关、当前节点与配置选择都需要各自确认；本次验证没有包含 iPhone 实机。

## 4. 日常场景切换

### 在家日常浏览

关闭 Shadowrocket，使用梅林网络。路由器保持大陆白名单模式：国内直连、海外使用香港主节点。日本或其他地区网站不因网站语言而自动切换到对应国家节点。

### 在家使用 GPT

开启 Shadowrocket，选择能正常访问 OpenAI 的节点，保持全局路由为“配置”。所有命中 `PROXY` 的服务都会随当前节点改变出口，而不是仅 GPT 切换出口。

梅林需要让客户端到相应节点入口的连接直连，以避免该加密连接又进入路由器代理。配套方案覆盖本地订阅中已核验的全部美国节点；公开仓库不包含私人入口地址。订阅新增节点、服务器地址或解析 IP 变化后，应按[梅林指南](../merlin/使用指南.md)重新核验并更新本地绕过名单。绕过的是节点入口，不是把 OpenAI 业务域名设为直连。

### 外出使用大陆热点或蜂窝网络

在需要访问海外服务的设备上开启 Shadowrocket。同一配置通过客户端独立分流，没有写死家庭路由器 DNS，也不要求先连接回家。

例如 Mac 连接手机热点时，Mac 自己应开启 Shadowrocket；不要假定手机的代理会自动覆盖共享给其他设备的热点流量。手机本身访问海外服务时，也需自行选择配置、节点并开启连接。

### 使用金融类 App

按使用习惯先关闭 Shadowrocket，再启动金融类 App。本配置没有金融类专属规则；某些 App 是否检测 VPN 或对运行环境有要求，应以 App 的实际提示为准，分流规则不能保证消除检测。

在家关闭 Shadowrocket 后，梅林仍然工作。如果需要确认完全不使用代理，应额外检查路由器状态，或改用确认没有其他代理的网络。

## 5. 基础验收

每次首次导入、更新节点或更换网络后，至少检查：

| 检查项 | 预期与判定 |
| --- | --- |
| 当前配置与路由模式 | 新配置已选中使用，全局路由为“配置” |
| 远程规则 | 43 个引用加载完成；失败项应先检查 URL、网络和客户端缓存 |
| 原生规则测试 | `chatgpt.com` 应命中 `PROXY`；`kimi.com` 应命中 `DIRECT` |
| 国内使用 | 微信、抖音、知乎、番茄及常用办公功能能正常使用；不能仅凭首页加载判断所有功能正常 |
| 局域网 | 家庭路由器和 NAS 可访问；有自定义名称时检查系统 DNS 解析 |
| 海外服务 | 使用预期节点测试目标服务的页面、登录和所需功能；HTTP 200 不等于完整业务正常 |
| 外出网络 | 在实际热点/蜂窝环境重新检查，不沿用家庭网络的测试结论 |

2026-09-23 已验证的是本地 Mac 实例：43/43 个远程引用加载、上述两个原生规则测试，以及 ChatGPT `robots.txt`、GitHub、百度的基础 HTTP 请求。公开脱敏版未重新在设备上加载，iPhone 与热点未实测；长期流式输出、语音及所有 App 子功能也不在已验证范围内。

## 6. 更新配置与远程规则

配置文件和远程规则是两种不同的更新：

1. 更新本仓库配置时，先备份当前使用文件和私有规则，再下载新版 `.conf`，导入并明确选中使用。
2. 仅刷新远程规则时，在当前配置的规则集/URL 管理入口使用下载或更新功能，确认全部加载完成。上游仓库更新不会证明设备已使用最新缓存。
3. 再做基础验收。某个源暂时失败时保留现有可用配置，不要盲目删除整层服务规则。
4. 订阅更新后，检查所选节点是否仍存在，并核验梅林中的节点入口绕过是否需要同步。公开 `.conf` 不维护私人的服务器 IP。

本地显式域名不会因刷新远程规则自动更新；服务新增域名、CDN 或登录依赖时仍可能需要补充。`GEOIP` 与 `FINAL` 是兜底，不能保证远程规则全部失效时仍有相同覆盖效果。

## 7. 常见问题排查

| 现象 | 先检查 | 后续处理 |
| --- | --- | --- |
| 国内 App 开代理后卡顿 | 是否使用“配置”模式；日志中失败请求命中 `DIRECT`、`PROXY` 还是 `REJECT` | 对照请求用途判断，不能只因某 App 是国内 App 就放行其所有域名 |
| 某功能命中广告拒绝 | `[Rule]` 中的 Advertising 规则 | 先备份，临时注释该行并重新加载验证；确认误伤后仅补必要例外，测试结束恢复拦截 |
| GPT 页面或登录失败 | 当前节点可用性、出口是否符合目标服务要求、OpenAI 请求是否均命中 `PROXY` | 区分节点、账号、DNS、广告误伤和服务自身限制；不要直接把整个服务改为直连 |
| GPT 流式输出或语音异常 | 连接日志、节点稳定性、实际使用的传输方式 | 代理 QUIC 阻断仅改善兼容性，不保证 HTTP/2、SSE、WebSocket 或语音全部正常 |
| 家中开启客户端后延迟较高 | 客户端节点入口是否被梅林再次代理 | 重新核验实际服务器域名与解析 IP，更新本地绕过；不要用伪装域名代替节点入口 |
| NAS 名称不可访问但 IP 可访问 | 系统 DNS 是否能解析别名，名称是否匹配 `[Host]` 的本地规则 | 在本地添加必要的名称解析或精确直连规则，不固定为他人家庭设备地址 |
| 外出网络解析失败 | 当地网络下主 DoH 与备用 DNS 是否可达 | 根据日志定位；本配置故意不让直连解析失败改走代理，必要时在本地调整可用解析器并复测 |
| 海外地区内容变化 | 客户端是否开启、当前所选节点 | 所有 `PROXY` 跟随当前节点；按目标服务需要切换后重新测试 |

修改规则时优先在本地副本操作。不要为排错启用 MITM、关闭证书验证、公开日志中的凭据，或把整个云厂商网段加入直连。

## 8. 私有规则与公开版差异

公开版保留 43 个远程引用，但移除了本地实例的一条私人 API 精确主机规则，并在第 10 层留下注释说明。若确有需求，复制成本地文件后再补充：

```ini
DOMAIN,api.example.com,PROXY
```

将示例主机替换为确需处理的完整主机，不要填写 URL 路径、订阅链接或密钥。需要优先直连的服务例外应放在广告或可能先命中的大类规则之前；企业 Work 域名不在本方案维护范围内。

更新公开配置时，这些本地私有改动不会自动合并。先备份，再逐项恢复确实需要的规则；不要为了保存私有设置而把完整本地文件直接提交到 GitHub。

## 9. 回滚

1. 关闭 Shadowrocket 连接。
2. 在配置列表重新选择此前保留的可用配置；若列表中没有，导入本地备份。
3. 恢复此前的路由模式与节点选择，重新开启连接并做基础检查。
4. 如仅需退出客户端代理，可保持 Shadowrocket 关闭；家庭梅林仍然工作。

Shadowrocket 回滚不会撤销梅林的名单或端口设置。路由器需要单独按[梅林使用指南](../merlin/使用指南.md)恢复本地备份。不要把一个平台的恢复当成两个平台均已回滚。
