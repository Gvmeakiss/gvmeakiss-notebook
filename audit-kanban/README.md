# 稽核工作进度看板（演示版 · Demo）

> **演示项目 · Demo app**：此目录为从部门内部工具脱敏泛化而来的通用离线看板演示应用。代码不含任何真实业务数据；演示数据全部虚构（`演示数据/` 内文件已声明虚构），公司名/部门抬头均已泛化，仅用于展示看板交互与构建方法。
> *This is a desensitized, generic offline-kanban demo derived from an internal department tool.* *No real business data is included; all demo records are fabricated.*

面向部门同事和经理的离线工作台账：同事在“我的工作”填写并下载提交，专人汇总，经理查看部门清单。支持手填百分比进度条、五类看板、Excel 模板与导入导出、冲突预览、JSON 备份恢复和周快照。

## 直接使用

将整个文件夹复制到固定位置，用 Chrome／Edge 双击打开 `index.html`。无需安装依赖或构建。首次打开为空台账。

- 同事：点击“我的工作”，选择姓名，更新进展，然后“下载我的提交文件”交给汇总同事。
- 汇总人：点击“汇总同事进展”，核对有变化的工作后确认汇总；每周“本周留档”，定期下载全部工作备份。
- 经理：在“部门看板”按模块、状态、负责人查看，列表／卡片可切换，点工作名称看详情。

数据仅在本机当前浏览器保存，各副本不自动同步。换浏览器、移动目录、清理浏览器数据前先导出完整备份。
