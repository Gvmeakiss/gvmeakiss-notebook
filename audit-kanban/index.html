使用帮助

按你的工作选择下面的步骤；详细说明包含字段示例、错误处理和完整演练。

打开详细使用说明与案例 ↗

1. 填报同事：新增、更新、提交
  1. 进入“我的工作”，填写与台账一致的姓名。
  2. 新事项点“新增工作”，原事项点“更新进展”，每周沿用原记录。
  3. 进度填 0–100 的整数，说明现阶段进展，未完成时填写下一步。
  4. 保存成功后点“下载我的提交文件”，确认下载完成，交给汇总人。文件包含本人全部工作，不受筛选影响。

例：专项由 60 更新为 85，进展写“样本复核结束，报告待确认”，下一步写“周五前确认并归档”。只有整项结束才勾选“是否完成”。

当前未保存的输入会在退出编辑时丢失，请先保存再关闭。

2. Excel 填写：模板、字段、注意事项
  1. 到“部门看板 → 汇总同事进展 → 下载填写模板”。已有事项使用个人工作表，在原行更新。
  2. 保留“工作台账”表名、表头和已有编号，一行一项工作。
  3. 日期填 2026-09-11 这样的有效日期；是否完成填是／否；完成时进度填 100。
  4. 保存为 .xlsx 后交给汇总人，数据区不要保留公式。

当前版本进度直接填数字 60 表示 60%，不要填 60% 或使用 Excel 百分比格式；100% 可能被误读成 1。新记录编号可留空，旧记录编号请保留。

3. 汇总人：检查文件与不同版本
  1. 在“部门看板”点击“汇总同事进展”，每次选择一份文件。
  2. 先看新增、相同跳过、冲突数量，预览阶段不会改动台账。
  3. 对变化项比较完整内容，逐条选择保留当前版或采用导入版；未选择默认保留。
  4. 同名提醒需核对是否重复创建；有错误则按行号修正文件并重新选择。
  5. 检查后点击“确认汇总”，确认完成提示。

例：台账 85%，同事误发旧文件 60%，应保留当前版。应用不会按更新时间自动覆盖；采用导入版会替换该条整项内容。

普通合并不删除未提及的工作，也不改变已有周报。

4. 经理：筛选重点、看详情和导出
  1. 进入“部门看板”，点“重置”回到部门全部范围。
  2. 点“已逾期”等统计卡，再按模块、负责人和关键词筛选。
  3. 列表便于比较，卡片便于阅读；点名称查看完整文字。
  4. “下载当前列表”导出当前筛选结果。

统计随筛选更新。绿色＝未逾期，红色＝已逾期，蓝色＝整项已完成；当天到期不算逾期。橙色进度条仅表示填报百分比。

5. 每周留档：保存与回看
  1. 本周文件汇总完成后，点“本周留档”，选择所属周的周一并确认。
  2. 保存的是全部门当前工作，不受筛选影响，同周可有多个版本。
  3. 进入“历史周报”选择版本，查看冻结的进度与状态；需要修改请返回当前台账。
  4. 留档后另行下载完整备份。

例：周一留档时未逾期，周三当前工作已逾期，周一历史仍保留绿色。选择旧周日期不会自动还原过去数据。

6. 备份恢复、换电脑与保存失败
  1. 日常在“备份与恢复”下载全部工作备份，确认 .json 下载完成。它包含当前工作和所有周报。
  2. 完整恢复先选择旧备份，再下载当前数据备份，并回选刚下载的文件进行校验。
  3. 核对数量、校验通过后再确认替换全部数据。日常同事提交使用普通合并。

复制应用文件夹不等于复制台账。换电脑、浏览器、路径或清理浏览器前请备份。保存失败时先下载未保存的工作，不要直接刷新或清理数据。

保存不等于提交，留档不等于外部备份。各副本不会自动同步；下载文件后仍需按部门约定方式交接。
