# 模板与范文交叉建模

模型是带出处和条件的审校规则集。它既不能从待改稿自证，也不能把成熟稿的旧格式覆盖到最新模板上。

## 1. 不同来源各自负责什么

| 来源 | 可提供的依据 | 不能替代的内容 |
| --- | --- | --- |
| 用户本次明确要求 | 任务范围、材料身份、交付形式、写作偏好 | 不明事实仍不能由编辑补定 |
| 最新有效模板 T | 当前结构、层级、格式、条件分支、标准用语 | 模板示例不是本项目事实 |
| 成熟原件 R | 段落组织、句式、语气、表达边界 | 旧格式、人员数据、制度年份、个案结论不迁移 |
| 待改稿 D | 被编辑的既有内容、主体、事实表述与判断 | 不作为审查自身的规范来源 |
| AI 生成的模型或意见 | 便于执行的中间产物 | 不能替代 T/R 原文成为直接证据 |

先从 T 建完整框架，再读 R 中与各节点对应的原文。相同句式多次出现，只能证明有成熟用法，不能因此成为强制要求。跨来源多数表决不能决定模板含义。

## 2. 每条规则先分类

| 性质 | 如何识别和执行 |
| --- | --- |
| 必须 | 用户或模板明确要求；记录原文及适用对象 |
| 条件适用 | 先记录触发条件，再记录选用分支；未知时不擅自选择 |
| 建议 | 可以采用；不能将其他合规写法判为错误 |
| 示例 | 仅借组织方式，不复制姓名、数字、年份、抽样比例或结论 |
| 模板自身差异 | 正文、批注、目录或示例不一致；列明分歧，不悄悄统一 |

模板使用长标题，而成熟稿用短标题时，短标题可作备选；不能仅因短就判定模板原式需要修改。模板本身没有固定字数、页数的，不由编辑增加限制。

## 3. 规则记录必须能回到原件

每条规则记录规则 ID、内容、性质、直接来源、适用条件、不可迁移信息和未决差异。按实际依据填写用户明确要求、T 的页及区域和/或 R 的对应页及摘录，不适用的来源可注明“不适用”。模板独有要求不必凑出成熟稿出处，R 的表达先例也不因此升级为硬要求。摘录只保留必要上下文，原件及内部引文留在本地项目。

```text
规则：职责与履职情况分别组织。
性质：按本次模板记录为必须或条件适用。
直接出处：模板页/区域；成熟原件页/段。
表达方法：职责说明负责范围，履职说明已有动作及原有结果。
边界：不把职责目标改成已实现成效，不把履职自述改成审计验证结论。
```

结构与表达规则若只能找到统一模型，却找不到用户要求或 T/R 直接依据，应重新判断其性质，必要时降为可选或撤回。清楚错字、重复、句法等纯文字问题可以由 D 原件直接判断，无需牵强引用范文；D 仍不进入规范池。

## 4. 按段落功能组织内容

将任命及职责、实际履职、审计程序、发现与事项、结论分开。按当次模板安排顺序和层级，不能只因其他稿出现某项身份、表格或程序就给 D 新增同类内容。

- 职责目标可描述应负责什么、目标是什么，不自动改成已经实现。
- 履职情况可保留既有动作、具体机制、达成情况和原有结果。
- 审计程序只承接稿件已有的检查内容与结果，不新增访谈、抽样或系统核验。
- 奖惩、监管、诉讼、监察等分类按模板和原稿分别表达，不借改标题互换类别。
- 结论及附件按实际适用分支处理，不由历史个案推定本项目有或无。

## 5. 模板适配不能偷换口径

模板与范文之间的差异应记录下来，例如处罚门槛写法不同、结论有无“重大”、正文与示例表格覆盖方面不同。比较门槛是否包含边界，以当次模板或原文定义为准；未明确时列为待定，不擅自替换比较关系。编辑不得选择一个更宽的口径后直接覆盖 D。

同理，某次模板在“无一般发现”分支仍要求保留特定附件，只能形成**该模板的分支规则**；不能推广为所有任中离任报告一律保留同一附件编号。附件清单、章节数量和文号类型每次重新核对。

## 6. 模型更新的完成条件

T/R 的当前版本与角色明确，D 没有混入规范池；每条硬要求有直接来源；示例、建议、分支与矛盾未混写；生成的提示词和意见使用同一组规则。来源更正或建议被证实有误时，模型及其示例一起修订，不能靠追加一段提醒让旧错误规则继续存在。

具体语义检查见[语言与语义边界](./03_语言与语义边界.md)，来源变更见[来源更正与错误产物清理](./05_来源更正与错误产物清理.md)。
