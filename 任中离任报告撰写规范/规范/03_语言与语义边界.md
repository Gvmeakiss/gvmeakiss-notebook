# 语言与语义边界

以职责履行情况为中心，表达中性、具体、精炼。编辑的目标是把已有内容写清楚，不能借润色增加事实、提高评价、扩大否定或重新认定责任。

## 1. 精炼前先保护语义

| 要素 | 必须检查的变化 |
| --- | --- |
| 主体与归属 | 本人、机构、团队、下属是否互换；机构荣誉是否变成个人功绩 |
| 角色与动作 | 负责、分管、组织、参与、协助、督促是否被替换成更强或不同动作 |
| 能力与状态 | “能够”是否变成“已经”；反馈已处理是否变成审计确认有效 |
| 时间与范围 | 完整任期、审计期间、统计期及截至日是否被合并或新增限定 |
| 数字与口径 | 百分比、分数、数量、增长率、金额、单位及比较门槛是否保持 |
| 条件与强度 | 必须、建议、目的、结果、因果和先后关系是否被新增或加强 |
| 否定与例外 | 未发现、未受到、重大、其他、全部及“除……外”是否改变覆盖范围 |
| 事项类别 | 内部处罚、监管检查、监管处罚、一般发现、重大责任及在途事项是否混用 |

不能只检查人名、数字相同就认为改写安全。语序移动也可能改变条件统摄范围；把日期放到数量前，可能为原数量新增统计期间。

## 2. 原有内容与编辑新增分开判断

原有政治要求、岗位目标、标准句、具体措施、管理机制、已有结果和外部评价，可以根据段落功能保留。不主动扩写经营效益、排名、贡献、赞誉、保证或承诺；原稿必要的指标、问题金额和具体结果也不能为避免“成效感”而一并删除。

“确保、全面、严格、提升、推动”等词必须结合语境审阅。职责中的目标、行动的目的和已实现的效果是不同命题。词表可以帮助检索，不能直接决定删除。

精简重复修饰时，要检查是否同时删掉了动作、机制名称、范围或具体成果。外部授奖、表扬属于原文记载事项，不能一律当成作者自我赞扬；保留原文也不代表本轮已经验证授奖事实。

## 3. 期间与指标不机械统一

- 通知日期、任职起点、完整任期、本次覆盖期及统计截至日分别保留。表面年份不同不自动构成错误。
- 年度指标可以与较短审计期间并列存在；不能由编辑自行截算，也不能借另一个项目的说明补写本项目缺月原因。
- 达成率、考核得分、按项目数量计算的达成比例和增长率不能互相替换。某比例超过百分之百，也不能仅凭外观改成满分或认定计算错误。
- 指标完成状况与经营成果真实性是不同判断。指标未达成不能推出数据不真实；模板需要真实性表述，也不能由编辑新增“经验证真实”。

原稿列举与总数看似不对应时，指出文本不对应，保留条件化处理；不擅改总数，也不补造漏列对象。

## 4. 处罚与结论分开处理

内部处罚和监管处罚分别对应各自栏目。监管检查次数不等于处罚次数，机构罚款不等于机构与个人合计，员工事项不自动归为负责人个人事项。“以上”“及以上”等比较门槛是否包含边界，以当次模板或原文定义为准；不擅自改变比较关系，也不预设两种写法必然不同。

三类结论独立判断：一般审计发现及建议、重大违规违纪或职业操守问题、重大在途或未了事项。历史处罚不自动等于本次新增发现，也不自动构成个人重大责任。“未发现正在调查事项”不能扩大为“没有全部在途或未了事项”。

分项写“重大问题”，汇总未写“重大”时，列明两处原句及范围差异，提供条件化方案；不为了词面统一自行增删程度词。“除已披露事项外”“其他”等例外也不能跨结论搬用。

## 5. 结构缺口和含义歧义各自处理

总述写“具体如下”而可见连续正文没有明细，是文本呈现缺口，不能直接宣布事项或证据不存在。标题属于监管事项，正文却是内部处罚时，不能只将“内部”换成“监管”，尤其不能由此创造“无监管处罚”的结论。

会议、活动等句子可能同时存在“组织某活动”和“参加某类活动”的读法。不能凭经验选取一种，也不能用模板示例的另一个会议名称覆盖原文。必要时保留原句，在批注中列出不同原意下的备选表达。

## 6. 抽象反例

下列例句为虚构示例，仅展示语义变化。

| 原意 | 不当改写 | 为什么不能直接采用 |
| --- | --- | --- |
| 督促团队更新台账 | 本人完成台账更新 | 督促责任变成亲自执行 |
| 参与讨论方案 | 主持决定方案 | 参与变成组织决策 |
| 具备复核能力 | 已完成复核 | 能力评价变成实际行为 |
| 安排复盘，以减少返工 | 复盘已消除返工 | 目的变成确定效果，程度也被加强 |
| 管理层反馈事项已处理 | 经审计确认处理有效 | 反馈状态变成审计验证结论 |
| 抽看部分记录未见明显异常 | 全部资料均准确 | 范围和结论强度扩大 |
| 某机构获得外部表扬 | 负责人个人获得认可 | 评价对象和归属改变 |
| 未发现重大操守问题 | 无操守问题 | 否定范围扩大 |
| 事项正在跟进 | 事项已经解决 | 完成状态改变 |

## 7. 判断是否需要修改

明确错字、病句、重复或层级问题可以修正；合规但可更简洁的写法列为可选；需要判断主体、统计含义或结论条件的列为条件化提示；有意保护的原句列为保留。原句保留不等于认可其事实或可直接定稿。

每次回对同时看“有没有多说”和“有没有少说”。过度删除与扩写一样可能失真。操作方法见[修改建议回对与全文修订](./04_修改建议回对与全文修订.md)。
