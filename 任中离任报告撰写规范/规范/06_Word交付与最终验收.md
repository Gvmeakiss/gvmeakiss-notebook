# Word 交付与最终验收

从照片重建的是可编辑修订稿。生成文件、打开成功和压缩包结构正常，都不足以证明文字完整、批注有效或版式可用。

## 1. 正文先完整，再处理版式

依据已经回对的当前修订全文，按有效模板结构生成 Word，避免从原始转录重新生成而恢复已改正内容。优先使用 Word 标题样式、原生段落、表格、脚注、页眉页脚及分页。正文不能由整页照片代替；人工换行和空格也不能替代稳定的表格或层级结构。

除已确认的修正外，保持可见原件的标题、数字、单位、脚注、表格行列和附件清单。模板与原件没有给出的样式参数不伪称精确还原；可以采用清晰、稳定的排版，并记录必要差异。若用户提供可编辑稿，优先在副本上修订，保留用户原件。

## 2. Word 与文本做内容对应

有配套 Markdown 时，选定一个内容主版本并记录同步方向。比较时覆盖正文段落、表格、脚注、附件清单和落款，只允许排版空白、Markdown 标记、目录生成及自动页码等明确的格式差异。

不能简单去掉全部标点或限定词后比较，否则可能隐藏负号、小数点、文号括号和否定范围变化。重复页眉页脚可按明确规则剥离，正文同名文字不得误删。

重点复核受保护字段：主体、角色动作、日期文号、期间、数值单位、阈值、重大程度、例外、事项状态和结论。相同文本只能证明转录与同步的一部分，仍需语义回对。

## 3. 原生脚注和批注单独验收

- 脚注必须有正文引用和对应脚注内容；不能只把小字移到正文末尾冒充脚注。
- 批注应能在 Word 中定位到对应文字，内容与意见清单一致；不把解释留在无人可见的外部 JSON。
- 用程序生成 DOCX 时，可检查相关 OOXML 部件、关系、内容类型、批注范围起止与引用 ID；结构通过后仍需检查实际显示和定位。
- 批注数量与脚注数量按本稿实际内容确认，不沿用上一对象的统计。PDF 通常不能完整呈现 Word 批注，渲染验收不能替代批注检查。

条件批注不能悄悄改变正文。正文已改而批注仍写“原句保留”，或正文留有占位却说明“已补齐”，均应退回修复。

## 4. 以最终渲染检查每一页

使用当前环境可用的文档渲染工具，将最终 DOCX 渲染为 PDF 或逐页图像并逐页查看。工具不可用时说明未完成的验收项，不据文件结构检查宣称排版通过。

| 区域 | 检查点 |
| --- | --- |
| 封面与目录 | 题名层级、文号日期、目录条目及当前页码对应 |
| 标题与正文 | 标题不孤悬，段落不裁切，不出现异常空白、叠字或缺字 |
| 中文字体 | 字形可见，字体回退和主题字体没有破坏间距或层级 |
| 表格 | 列宽合理，短字段不拆成逐字竖排，长名称不出现不必要的单字尾行 |
| 跨页内容 | 表头按需重复，行高不裁切，续文与脚注归属清楚 |
| 页眉页脚 | 页码系统一致，无正文重叠，不误把封面计入正文定位 |
| 落款与附属结构 | 签署位置、附件清单和“本页无正文”等与实际页面匹配 |

新稿页数由实际排版决定，目录不能复制扫描页码。检查器报告有多少页，不等于目录的每项位置已经核对。

如果中文字体加载异常，优先使用本次进程的字体配置、明确字体设置或调整文档样式，避免修改全局系统环境。修复字体后重新检查行距、分页和表格；必要时按实际字形调整固定行距、段间距及单元格高度，不能靠缩小到难以阅读来消除溢出。

最终保存后再次渲染，逐页验收当前版本。验收后若改了字体、边距、段落、表格或内容，旧页数和目录证明应失效并重查。

## 5. 交付状态据实说明

对用户提供当前 Word、配套文本、修改意见及回对结果的清晰入口。渲染图片、临时 PDF 和生成器默认属于验收工作文件，不把缓存目录当成正式交付目录，也不自动打开全部预览。

含占位、识读疑点或条件项时，标为“文字修订稿”或其他明确的待定状态，说明剩余事项。不得写成“事实全部核实”“无须再判断”或“可直接签发”。

## 6. 最终完成记录

完成记录至少包括：当前 T/R/D 身份与版本、规范池排除 D 的检查、来源及 OCR 保护、旧产物去向、意见回对、完整稿覆盖、Word 与文本对应、脚注及批注、逐页渲染、目录定位、链接和剩余未决项。

不同证明不可替代：指纹证明内容字节关系，链接检查证明路径可达，逐页渲染证明所见版式，语义回对证明改写边界。每项完成声明都要对应当前对象、当前输入和当前输出；未检查的项目保持未检查。
