# 审校与修订指令

使用前填写本地材料的完整路径或稳定 ID、当前角色和交付要求。以下指令不能替代读取本次材料，也不能把上次的人员、数字、结构或结论带入新项目。

## 1. 首次建档与建模

```text
请先审阅整个目录结构，任务仅限底稿撰写、文字结构和模板适配。
本次最新模板 T：[完整路径或来源ID及版本]
成熟原件参考池 R：[精确列出]
本次待改稿 D：[完整路径或来源ID及版本]
其他材料用途：[排除、停用或待确认]
交付要求：[修改意见；是否需要完整Word和配套文本]

先建立来源身份及角色清单，记录版本指纹和页序映射。待改稿不得进入规范池。
照片和扫描件使用可用本地OCR批量提取，原始输出与校核转录分层。
首次有效版本逐页核对正文、表格、脚注、修订痕迹和批注；已有同版材料包先复用。
记录无法辨认的字符和结构疑点，不靠常识补齐。

用最新模板建立结构与格式规则，区分必须、条件适用、建议、示例及模板自身差异。
成熟原件只提供与模板相容的表达方法，不覆盖新格式，不迁移个案事实或结论。
每条规则记录直接模板或成熟原件出处、适用条件和允许的表达强度。
完成可检索的材料索引及统一审校模型，不使用历史AI改写稿建立规范。
```

## 2. 意见、回对与完整修订稿

```text
依据本次有效模型审阅D，并将每条建议直接回对T/R/D原件。
只处理撰写，不新增业务资料核查、制度效力审查或责任认定。
意见分为明确文字修正、可选精炼、条件化提示和原句保留；OCR纠错另列。
每项给出原位置、原句、问题、改法、直接来源、处置性质及语义保护检查。
格式和表达依据按实际引用用户要求或T/R；清楚错字、重复和句法可直接据D，不为凑齐引文虚补来源。

保留政治要求、原岗位目标、模板标准句、具体措施、机制、已有结果和外部评价。
不按“确保、全面、严格、提升”等词表机械删除，也不主动扩写效益、功劳、赞誉或承诺。
检查主体、角色、动作强度、期间、数字口径、状态、否定、重大程度和例外。
职责目标不改成已实现效果，履职自述不改成审计验证，机构事项不改成个人事项。
一般发现、重大违规或操守、在途未了分别判断，不互相推导。
不能仅为词面一致而统一期间、比较门槛、重大程度或例外范围。

如果建议与直接来源不符，撤回或调整，并同步修模型、提示词、摘要和替换段落。
如要求完整修订稿，覆盖原件可见全文与表格、脚注、附件清单、落款等，按约定格式交付完整可编辑稿。
明确改法落实正文；可选精炼保留选择；条件事项不代选，用批注或独立说明表达。交付Word时使用原生批注。
文字缺口或类别错位无法恢复时作明确编辑占位，不编造明细或“未发生”结论。
OCR待辨、编辑占位和条件批注分别管理；附件只有清单时不编造附件正文。

回对意见、替换段落、全文和批注，记录当前输入版本。
交付Word时检查原生脚注和批注，渲染最终Word并逐页查看，更新目录页码；有配套文本时检查内容一致。
交付说明据实列出剩余事项；含待定项的文件称修订稿，不称可直接签发的正式定稿。
```

## 3. 材料身份更正后重做

```text
本次更正：[来源ID、旧角色、新角色及用户确认依据]
新的有效T/R/D清单：[逐项精确列明]
错误处理结果的清理范围：[按本次授权列明]

先停用受影响产物，按“来源角色→索引→规则→模型/提示词→意见→全文/批注→Word/渲染→完成记录/入口”展开影响。
记录每个旧生成文件的保留、迁移、重建或删除去向及指纹，不只替换名称。
保留用户原件和内容未变的正确原始OCR；更新独立角色元数据及校核页用途。
相同内容移动不算新增，照片、逻辑页和OCR记录分别统计。

将新D全部排出规范池，撤销由它支持的规则，从当前T/R原件重建。
旧D恢复为R时只用成熟原件，不用此前AI改写结果。
按授权删除错误对象意见、完整稿及派生渲染和完成证明，修复会重生错误的生成器和配置。
重新对当前D编制意见和完整稿，不沿用旧对象的条目数、页数、批注数或完成声明。
最后验证原件/OCR保护、依赖、删除去向、入口链接、语义、Word及最终渲染。
只对当前实际检查作完成声明，未决项单列。
```

## 4. 建议独立复检

```text
请作为独立文字审阅者，使用当前同版T/R/D原件及最终意见、全文和批注复检。
先查OCR假问题，再查建议有没有把模板示例当要求、删除原有具体内容、改变主体角色或扩大结论。
双向核对：原稿重要内容有没有丢失；改稿是否新增事实、程序、义务、因果、效果或判断。
逐条指出需撤回、降为可选、改成条件化提示或保持原句的项目，给出直接出处和理由。
记录实际输入版本。正文、段落或批注后续再变更时，补核相关部分，不能沿用旧通过记录。
```
