# 可复用矢量组件使用说明

这组组件是按当前项目配色和页面习惯整理的可选备件，面向 H5、可编辑 PPT、宣导海报和长图。当前共 24 个 SVG，分成基础组件和扩展组件两组。全部为 SVG，可无损缩放；需要修改时可在 Figma、Illustrator、Inkscape 等矢量工具中编辑，也可在 PowerPoint 中作为 SVG 插入后取消组合进行调整。

> 颜色依据项目复用规范整理，不能把本组色值直接表述为中国平安正式 VI 标准。正式对外材料仍以公司最新品牌规范和审核意见为准。

## 具体使用方法

### H5

- 采用 `01`、`02`、`03`、`04`、`05`、`06` 和 `11` 组织页面关系；一屏只保留一个主标题和一个主要信息模块。
- 竖版页面推荐以 `11_H5竖版标题区.svg` 作为顶部结构，以 `03_浅橙信息卡.svg` 或 `06_风险三级对照表.svg` 作为内容承载。横向流程过密时，优先拆成两屏，不强行缩小。
- `08_海报橙色角标.svg` 只作为局部提示，放在内容区外沿；不要与大面积橙色标题带同时占据两个视觉中心。
- SVG 可直接作为图片使用；若后续需要改字、改节点或改颜色，优先保留原始 SVG，不要先导出成 JPG/PNG。

### PPT

- `02`、`04`、`05` 和 `06` 适合做页面骨架。正式交付时，标题、表格、节点和连接线应使用 PPT 原生文字与形状重建，保证经理后续能直接修改。
- `07_圆角表格外框.svg` 用作外轮廓参考：表格整体做圆角，内部网格保持直线和清晰层次，不要把每个单元格都做成独立圆角块。
- 实橙标题带、表头和流程节点中的文字统一白色加粗；浅橙和浅灰区域使用深灰字。
- `09_右下角页脚线.svg` 的页码、部门和年份均为占位信息，交付前必须替换为本次项目的真实信息。
- 不把整页 SVG 当作 PPT 唯一内容背景；需要编辑的正文必须单独放置。

### 海报和长图

- `08` 适合做“提醒”“重点”“更新”等短标签；`12` 适合放在底部，承载行动提示、咨询入口或发布日期。
- 海报主标题可使用 `02`，正文用白底或浅灰分区承载。照片背景上叠字前先加白色半透明或浅色内容区，确保深灰字可读。
- A4 或长图中按比例放大，不改变圆角和边线的相对关系；信息较多时通过分区增加密度，不用大量装饰填空。

### 快速组合方式

- **封面**：`24_封面橙色底纹.svg`＋`01_白底标题橙线.svg`；照片背景只选一张，不再叠加 `22`。
- **目录**：`21_PPT目录页签.svg` 或 `02_实橙标题带.svg`；章节较多时统一编号，不混用不同页签样式。
- **流程**：三段用 `04_三段流程节点.svg`，三段带办理关系用 `23_流程箭头组.svg`，四个关键时点用 `15_四级时间轴.svg`，七步总览用 `05_七段流程节点.svg`。
- **职责**：需要显示主体与动作的，用 `16_责任泳道.svg`；只需要三个角色并列时，使用页面原生卡片，不要把泳道压缩成小字。
- **规则或风险**：对照变化用 `14_两列对照卡.svg`，等级路径用 `06_风险三级对照表.svg`，字段较多用 `07_圆角表格外框.svg`。
- **提醒和数据**：一句话提醒用 `03_浅橙信息卡.svg` 或 `13_浅灰分区左边栏.svg`；单项数字用 `17`，单项比例用 `18`，H5 办理进度用 `19`。
- **收尾**：海报或长图用 `12_海报底部行动带.svg`，需要二维码时在 `20_海报二维码留白框.svg` 中替换，PPT 页脚用 `09_右下角页脚线.svg`。

## 推荐尺寸

| 场景 | 画布起点 | 组件使用建议 |
| --- | --- | --- |
| PPT | `1280 × 720`，16:9 | 标题带高度约画布的 8%—12%；主模块圆角约 14 px，表格外轮廓约 12—14 px |
| H5 | `750 × 1334` 或 `1080 × 1920`，9:16 | 先确定标题和内容安全区，再按比例缩放；不把横向七步流程压成不可读的小字 |
| A4 海报 | `2480 × 3508`，300 dpi | 标题和行动带留足边距；照片、角标和正文至少保留一处明显留白 |
| 长图 | 宽度 `750` 或 `1080` | 以内容分段为主，组件只在章节转换或关键提醒处使用 |

## 视觉禁用项

- 主填充橙 `#ED6E40` 上使用黑色或细体正文。
- 任意新增橙色、荧光渐变、高饱和红橙或大面积深色底，导致全稿失去层次。
- 一页同时使用多个大标题带、多个角标和多个强流程模块。
- 把圆角表格拆成密集的小卡片，造成网格关系不清。
- 用装饰素材遮挡标题、数字、表格边界或页脚信息。
- 将占位文本、页码、部门和日期直接带入正式材料。
- 在 PPT 中用整页图片替代可编辑文字、表格和流程对象；不增加演讲者窗口。

## 交付前检查

- [ ] 实橙底文字为白色加粗，浅色底文字为深灰。
- [ ] 同一页面的标题带、流程节点和表格外框圆角半径一致。
- [ ] H5 横向关系没有被压缩到无法阅读；PPT 文字和表格仍可修改。
- [ ] 海报的标题、正文、行动带形成清晰层级，角标只承担辅助提示。
- [ ] 页脚、页码、年份和部门信息已经替换，占位文本已清除。
- [ ] 导出 PNG/PDF 后重新查看，确认没有裁切、锯齿、低对比或错位。
