# 组件调用速查

下次制作时先按“载体＋页面目的”选组件，再按内容量决定是否拆页。下面的写法可以直接交给 AI 或设计同事作为调用指令。

## 直接调用模板

| 页面目的 | 直接调用 | 替换内容 | 组合限制 |
| --- | --- | --- | --- |
| 封面 | `24_封面橙色底纹.svg`＋`01_白底标题橙线.svg` | 项目名、副标题、部门、日期 | 只保留一个主标题；不要再叠加大面积照片 |
| 章节页 | `11_H5竖版标题区.svg`（H5）或 `02_实橙标题带.svg`（PPT/海报） | 章节名、页次 | 实橙底只用白色加粗字 |
| 目录 | `21_PPT目录页签.svg` | 编号、章节名称 | 同一目录统一一种页签样式 |
| 七步总览 | `05_七段流程节点.svg` | 七个步骤名称 | 名称过长时拆页，不压缩字号 |
| 三段流程 | `04_三段流程节点.svg` 或 `23_流程箭头组.svg` | 阶段、动作、结果 | 二者择一，不同时出现 |
| 四个关键时点 | `15_四级时间轴.svg` | 阶段、日期、办理时点 | 时间点超过四个改用表格或拆页 |
| 责任衔接 | `16_责任泳道.svg` | 主体、动作、交接 | 每个泳道保留 2—4 个动作；再多就拆页 |
| 调整前后 | `14_两列对照卡.svg` | 原做法、本次调整 | 两列内容按同一维度对齐，不写长段落 |
| 风险分级 | `06_风险三级对照表.svg` | 等级、条件、办理路径 | 等级名称和判定条件以有效材料为准 |
| 字段规则 | `07_圆角表格外框.svg` | 字段、要求、责任、时点 | 只做整表外轮廓圆角，内部网格保持直线 |
| 一句话提醒 | `03_浅橙信息卡.svg` 或 `13_浅灰分区左边栏.svg` | 提示标题、操作要求 | 一卡只写一个动作或一个注意点 |
| 重点数字 | `17_重点数字徽章.svg` | 比例、期限、数量 | 数字必须能回溯到有效材料，单位写全 |
| 单项指标 | `18_指标环形占位.svg` | 完成率、状态、指标名 | 未有真实数据时保留占位并标记待补，不虚填 |
| H5 办理进度 | `19_H5进度条.svg` | 已完成比例、当前阶段 | 同一页最多一个主要进度条 |
| 角标提示 | `08_海报橙色角标.svg` | 重点、提醒、更新 | 只作为辅助标签，不承担正文 |
| 海报二维码 | `20_海报二维码留白框.svg` | 真实二维码、说明文字 | 发布前替换占位二维码并测试扫码 |
| 海报收尾 | `12_海报底部行动带.svg` | 联系人、入口、行动提示 | 保持短句，不塞入整段说明 |
| PPT 页脚 | `09_右下角页脚线.svg` | 部门、年份、页码 | 替换全部占位文字后再导出 |

## 替换顺序

1. 先确定页面目的和信息关系，再选一个主组件。
2. 替换标题、正文、步骤名、数字和页码；占位文字不能直接进入正式交付。
3. 根据内容量调整画布和组件尺寸，保持圆角、边线和内边距比例，不为填空白添加第二个主组件。
4. 检查文字颜色：`#ED6E40` 底只用加粗白字，`#FFE3D4`、`#F2F2F2` 和白底用深灰字。
5. H5 检查手机预览，PPT 检查原生编辑，海报检查导出 PNG/PDF 和二维码。

## 复制给 AI 的简短指令

> 从 `internal-audit-reform/素材库/可复用矢量组件/` 选择组件。先按页面目的匹配：封面用 24＋01，目录用 21，七步流程用 05，职责衔接用 16，调整前后用 14，风险分级用 06，字段表用 07，提醒用 03/13，重点数字用 17，指标用 18，H5 进度用 19，海报二维码用 20，收尾用 12，页脚用 09。沿用 #EA5A26、#ED6E40、#FFE3D4、#333333、#F2F2F2、#C7C9C9 和白色；实橙底使用加粗白字，浅色底使用深灰字。PPT 保留原生文字、表格、形状和连接线，不把整页做成图片；H5 和海报保持内容层级，不堆叠装饰。
