# 素材库

本目录存放内部稽核整改流程项目可复用的背景、建筑侧边元素和页面组件。素材主要服务于 H5、可编辑 PPT、宣导海报和长图。

## 目录

| 目录 | 内容 | 适用说明 |
| --- | --- | --- |
| [背景图](背景图/) | 背景照片、底纹和建筑氛围图 | 封面、章节页、海报背景；使用时注意文字区域的对比度 |
| [侧边元素](侧边元素/) | 建筑、城市和线稿侧边图 | H5、PPT、海报的侧边或底部装饰，避免压住正文 |
| [页面元素](页面元素/) | 已使用或整理过的页面配图 | 作为页面构图参考，优先选择少量辅助元素 |
| [可复用矢量组件](可复用矢量组件/) | 新增 SVG 标题带、流程节点、圆角表格、页脚和海报组件 | 可缩放、可改色、可复制；使用前阅读该目录 README |

## 使用总则

1. 当前项目色板以强调橙 `#EA5A26`、主填充橙 `#ED6E40`、浅橙 `#FFE3D4`、深灰 `#333333`、浅灰 `#F2F2F2`、边线灰 `#C7C9C9` 和白色为准。该色板是本项目的复用色板，不宣称为中国平安正式 VI 色值。
2. 实橙底配加粗白字；浅橙、浅灰和白底配深灰字。不要在主填充橙上放黑色正文。
3. PPT 交付必须保留文字、表格、流程和卡片的编辑能力。SVG 用于快速搭建和视觉参考，正式 PPT 可按 README 中的方式用原生形状重建。
4. 一页只设置一个主要视觉重点。背景照片、角标、流程节点和装饰线应服务于内容关系，不要为了填空白堆叠素材。
5. 使用完素材后，须逐页检查文字对比度、圆角是否错位、图形是否裁切，以及导出后的显示效果。

具体组件、场景和尺寸建议见 [可复用矢量组件/README.md](可复用矢量组件/README.md)。
