# 内部审计整改流程优化｜电脑邮件版宣导海报

本目录保存本次确认版的两页长图海报，以及用于后续复用和修改的 HTML/CSS 构建源文件与配图。

本海报作为视觉和制作方式参考保留。当前18页口播及业务依据见[案例定稿入口](../../案例/20261019_内部审计整改流程优化/README.md)；本轮未重新制作海报，不能据此认为海报已与最新口播逐项同步。再次使用或修改业务文字时，先按现行材料核对。

## 成品

- `内部审计整改流程优化_宣导海报_电脑邮件版.png`：2880 × 4800 PNG，适合插入电脑邮件正文。
- 第一页保留“深化整改、流程优化、标准统一”三项目标；第二页保留七个办理环节：任务下发、成因分析、措施制定、过程追踪、验收质检、业审联动、合规考核。

## 复用

1. 修改 `build_desktop_poster.py` 中的文字、布局或颜色。
2. 运行 `build_poster.py` 生成 `poster.html`。
3. 使用已配置好 Chromium/Playwright 环境的 `render_poster.cjs` 导出 PNG，并按本次交付要求检查文字溢出、遮挡、外部请求和七个环节是否完整。

`poster.html` 是当前确认版的可直接查看快照；`assets/` 中的两张透明配图为本海报的装饰素材。`配图生成说明.md` 保留了配图用途和生成提示，便于后续制作风格一致的版本。

本目录不包含原始照片、内部核对底稿、临时审阅截图或缓存文件。复用新项目时，必须重新核对原始材料中的部门、时点、比例、阈值和流程口径。
