# 本轮对话确认与复用要点

确认日期：2026-10-20。本文整理对话形成的最终要求，供下次接手使用；不保存已被覆盖的试写稿或把中间判断当作标准。

## 材料与用途

- 当前业务内容以经理修改后的《内部审计整改流程优化与操作详解》18页扫描材料为准。
- 口播用于向领导汇报，并向内控稽核、合规审查等相关条线说明流程要求。
- 旧稿可以参考讲述方式，但不能恢复现行PPT已删除或调整的业务内容。
- 领导要求名称符合实际、语言朴实、把要求讲清楚，不造“七步法”等包装性新词。

## 最终表达要求

- 能直接朗读；不写“这一页主要说明”等页面介绍，不照念表格，不堆空泛总结。
- 听众有专业工作能力，保留必要信息密度，避免基础概念教学和刻意降低表达层次。
- 自然感来自重点、句长和衔接安排，不来自新增案例、推断、效果判断或操作要求。
- 口播正文不含来源、OCR行号、审校提示或制作过程；核对依据另放。

## 本轮明确的业务边界

| 事项 | 最终采用的表达边界 |
| --- | --- |
| 两类整改事项 | 稽核项目发现的问题和三函涉及的整改事项统一纳入整改闭环。发起人、接收人、发送节点分别按PPT说明，不由此推导后续办理流程不同。 |
| 措施反馈 | 五个工作日对应《后续整改措施表》的反馈，成因分析与措施一并提交；不自行增加审核审批也须同期完成的要求。 |
| 成因与措施 | 保留分析结论作为措施制定基础、二者一并反馈的关系，不增加额外前置条件。 |
| 追踪与验收 | 只讲材料明确的责任、动作、频率、比例和不通过条件，不自行补充具体检查方法或顺序。 |
| 完成率评分 | 用户已确认100%不扣分，95%、90%、85%分界值归入较高完成率档。不据此再编造容差、取整等评分规则。 |

上述具体口径只适用于本案例；下一项目须重新核对。

## 问题如何沉淀为标准

本轮暴露的是连接语也可能增加业务含义：即使名称、数字都正确，整句仍可能暗示未确认的差异、时限或义务。因此，复核同时做“材料到口播”的覆盖检查和“口播到材料”的逐句语义检查。用户指出一处后，应通篇检查同类表达。

执行规则已经写入[口播语言规范](../../复用规范/03_口播稿内容整理与语言规范.md)、[句式对照](../../复用规范/04_口播句式对照.md)和[语义核对与定稿入库](../../复用规范/07_口播语义核对与定稿入库.md)。这些文档及现行稿共同构成下次复用入口，不要求下次AI自行从聊天过程判断哪一版有效。
