# 内部审计整改流程优化口播稿交叉复核说明

核对日期：2026年10月19日

核对对象为经理修改后的18张PPT扫描图片、新口播稿，以及领导关于对下发材料措辞的意见。新版图片位于“夸克扫描王_内部审计整改流程优化与操作详解”文件夹。旧18页PDF及2026年10月16日口播稿仅用于识别变化，办理要求以新版PPT和本次用户补充说明为准。

口播稿按图片文件名括号中的1至18顺序对应页面。本说明用于复核，不属于口播正文。

## 一 复核结论

新版PPT的18页内容已逐页核对。标题、章节表述、责任主体、办理时点、风险分级、审批流程、验收比例和考核范围均已对应检查。新增的重新审批、审批材料反馈、审批形式和考核具体情形已写入稿件。

稿件已按领导要求使用朴实表述，说明各方需要办理的事项，不将现有流程优化描述为行业项目或全新方法，不将团队制度和流程设计归为汇报人个人成果。口播正文没有来源标注、OCR行号、编写说明或审校提示。

已补充完成朗读表达复核：删除“这一页主要说明”等页面介绍、重复预告和空泛收尾，改为直接陈述业务要求或简短承接。修改前后已逐段比对，职责、办理时点、审批路径、验收要求及考核口径保持一致；Word与文字版内容一致。

## 三 领导意见落实

| 核对事项 | 处理结果 |
| --- | --- |
| 项目名称应符合部门实际工作 | 统一为“内部审计整改流程优化与操作详解”。 |
| 不造新词或方法名称 | 口播已清除“革新”“改革”“七步法”“七步流程”“五维分析工具”“三不通过原则”等旧表述。 |
| 语言朴实，把要求讲清楚 | 用实际责任人、动作、材料、时限和处理结果说明工作，避免“全链路”“赋能”“倒逼”“兜底”等概括。 |
| 保留必要的专业和内部名称 | 保留三道防线、三函、风险分级、业审联动等PPT已有业务称谓，并解释具体工作；未将“少造词”理解为删除业务要求。 |
| 不夸大已有流程调整 | 使用“在原有流程基础上细化和完善”的口径，不写成全面改革或全新体系。 |
| 不改变要求强度和范围 | 保留期限中的“原则上”、审批渠道中的“不建议”、风险判定的“参考”、考核的总部范围及总部“协助”机构落实等限定。 |

## 四 关键要求抽核

- 任务发送：稽核项目在处罚小组结束后立即发送；指令函、警示函在评审会通过后发送；知询函与稽核部公邮同步发送。
- 反馈：五个工作日内反馈《后续整改措施表》，成因分析随措施一并提交。
- 责任人及对接人：机构整改责任人中级及以上，总部初级及以上；机构由合规部负责人对接，总部由合规管理室负责人（郝瑞经理）对接。
- 期限及重审：整改完成期限原则上不超过三个月，到期无法完成需重新审批。
- 审批：高风险经上级、合规对接人及部门长或分管总审批；中风险经上级和合规对接人审批；低风险经上级审批。材料反馈稽核对接人，完善底稿。
- 验收质检：业务部门或项目组自验后实时提交；稽核条线每月20日验收；问责室季度抽检并回溯，高风险100%、中风险不低于30%。未扩大为全部事项逐单接受三级全量检查。
- 沟通与考核：业审联动按月或每两个月开展；考核由法律合规部发起、问责室统筹，监察、专项、远程团队配合，按半年或年度组织，范围为总部涉及整改的各部门。

## 五 本次补充确认的考核口径

PPT第17页原表将95%—100%、90%—95%、85%—90%写为相邻区间，边界存在重叠。用户已于本次会话确认：完成率100%不扣分，分界值按较高完成率档处理。口播据此采用以下表述：

| 完成率 | 扣分 |
| --- | --- |
| 100% | 不扣分 |
| 达到95%但未达到100% | 0.5分 |
| 达到90%但未达到95% | 1分 |
| 达到85%但未达到90% | 1.5分 |
| 低于85% | 2分 |

未将“评定不会那么严格”等沟通性说明写入宣贯口播，也未自行增加四舍五入、容差或其他评分规则。

完成质量加分保留PPT列示的两类情况：一是重大风险提前整改并取得降低风险敞口、减少损失、挽损或增加现金流等效果；二是从单一产品或领域延伸至部门内其他产品或领域的风险防控，落实至少一项流程或制度优化。PPT未列具体加分分值，稿件未补写。

## 六 原PPT需留意的显示与称谓问题

1. 第6张目录图片页脚显示“07/18”，第9张目录图片页脚显示“10/18”，与文件顺序不一致。口播按第6、9页正确对应，未修改原图片。
2. 第10页列“问责规划室负责人”，第15页概述使用“规划问责室”。口播在第10页保留具体抄送名称，其余统筹、质检职责统一称“问责室”，未自行确定新的正式组织名称。
3. 第4页概述“定稿即启动”，第5、10页明确具体发送时间。口播分别说明整改启动衔接与任务发送节点，未将两者混为一个时点。
4. 第17页评分边界已按用户补充口径明确。若后续更新PPT，可同步将区间改为本说明第五部分的表述，保持显示与口播一致。
