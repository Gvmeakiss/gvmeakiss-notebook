# 照片与 PDF 材料整理的方法依据

查阅日期：2026-10-20。下面区分外部文档说明的事实与本项目据此选择的工作方式；未要求接入这些厂商服务，也未上传项目材料。

| 主题 | 一手资料说明 | 在工作流中的采用方式 |
| --- | --- | --- |
| 阅读顺序 | [W3C：PDF3](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF3)说明，PDF 的逻辑阅读顺序与文档结构有关，多栏和复杂版式需要核对 | 逐页保存区域和阅读顺序；不能把 OCR 拼接顺序当语义顺序 |
| 提取位置与样式 | [PyMuPDF：Text recipes](https://pymupdf.readthedocs.io/en/latest/recipes-text.html)说明，普通提取可能不按自然阅读顺序；文本块提供位置，文本 span 可包含字体、字号和颜色属性 | 原生 PDF 优先读取已有文本和属性，再核对版面；扫描照片不能因此宣称取得原生字号或颜色 |
| 结构化 Markdown | [Microsoft：Markdown elements](https://learn.microsoft.com/en-us/azure/ai-services/document-intelligence/concept/markdown-elements?view=doc-intel-4.0.0)说明结构化输出可包含标题、表格、图及页元信息，复杂表格可用 HTML 保留合并单元格 | 采用逐页 Markdown 与结构记录；复杂表格保留行列/合并关系，不能仅抄成一段文字。该文档介绍一种实现，不能据此保证任意转换器都准确 |
| 拍照颜色偏差 | [Adobe：Camera Raw color and tonal adjustments](https://helpx.adobe.com/camera-raw/desktop/using/make-color-tonal-adjustments-camera.html)说明白平衡、色温和色调会影响照片中的颜色表现 | 拍照取色标为估测；正式色板与观察色分开，不能由照片恢复并认证品牌 VI 精确值 |
| 文字可读性 | [W3C：Contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)规定普通文字及文字图片的对比度基准为 4.5:1，大字为 3:1 | 在最终显示尺度下检查颜色搭配。它是可读性参考，不替代用户视觉要求，也不代表通过全部 WCAG 条款 |

本项目的实施结论：采用“来源清单＋逐页原文/摘要＋结构关系＋视觉记录＋疑点”的材料包。Markdown 是便于检索的主入口，原图继续作为疑点追溯依据；结构和配色是否理解准确需要独立记录与复核，不由转换成功、OCR 分数或文件哈希代替。
