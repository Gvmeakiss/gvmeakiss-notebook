# 内部审计汇报、H5 与海报复用项目包

这套资料把 H5、PPT、电脑邮件长图和海报的制作方法集中在一个项目包中。仓库包含可编辑 PPT、逐页口播稿、统一视觉系统、内容核对方法、H5/海报设计规则、扫描参考和配图库。下次使用时先确定最终载体和交付结果，再按规范处理新材料；不要直接把本次项目的具体业务口径套用到新项目。

## 从哪里开始

1. 先阅读 [项目导航与结果导向](./复用规范/00_项目导航与结果导向.md)，判断要交付 PPT、H5 还是海报。
2. 阅读 [AI协作约定](./AGENTS.md)，再按需阅读复用规范：
   - [H5、海报与邮件长图设计](./复用规范/06_H5海报与邮件长图设计.md)
   - [配色与视觉设计要求](./复用规范/01_配色与视觉设计要求.md)
   - [内容整理与页面规划要求](./复用规范/02_内容整理与页面规划要求.md)
   - [口播稿内容整理与语言规范](./复用规范/03_口播稿内容整理与语言规范.md)
   - [口播句式对照](./复用规范/04_口播句式对照.md)
   - [PPT 页面规划与可编辑交付](./复用规范/05_PPT页面规划与可编辑交付.md)
3. 查看 [15页可编辑PPT](./交付成果/内部审计整改革新_可编辑终稿.pptx)、[逐页口播稿](./交付成果/内部审计整改革新_15页PPT配套口播稿.md) 或 [电脑邮件版海报](./交付成果/宣导海报_电脑邮件版/)。
4. 收集本次项目的原始材料、H5或截图、经理意见、规则文件和邮件模板。先核事实与职责时点，再写口播或正文，最后做页面设计。
5. 按需从 [配图素材库](./素材库/) 选图，不必全部使用。保持图片比例，给正文和流程留出阅读空间。
6. 若需要参考最新页面组织，查看 [18 页经理修改版扫描参考](./参考资料/最新经理修改版18页PPT扫描参考/)。扫描页只用于参考，不替代可编辑 PPT。

## 下次交给 AI 的任务模板

```text
请先阅读 internal-audit-reform/AGENTS.md、README.md 和复用规范中的要求。
我将提供新项目的原始材料、现有H5/截图和经理意见。请按顺序：
1. 提取并核对事实、主体、职责、条件、时点、数字和流程，列出冲突或缺失；
2. 先形成逐页内容规划和能直接照读的口播稿，口播稿不要出现来源页码、OCR行号或制作说明；
3. 按最终口播和内容规划制作可编辑PPT，优先原生文字、形状、表格和流程，不把整页做成图片；
4. 可从素材库挑选少量合适的配图，保证内容完整、可读和视觉统一；
5. 逐页对照原始材料、经理意见、口播稿与PPT，核对内容覆盖并检查最终渲染。
完成后只保留本次最终PPT和口播稿等明确交付成果，过程文件另行收纳。
```

## 本套资料的复用边界

本项目的页面结构、视觉规则、口播写法和工作流程可作为制作参考。15页PPT中的职责名称、风险条件、金额阈值、处理时限、比例、年份、审批链和实施安排都属于本项目口径。新项目必须以新提供的有效材料重新核实这些信息；没有依据的内容不要补写。

口播稿按PPT页码逐页对应，正文可直接照读。复用时同步更新PPT和口播，移除已取消内容和旧页码，不在口播中保留OCR、照片页码、来源说明、制作提示或演讲者窗口。
