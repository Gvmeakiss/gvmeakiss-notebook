# 内部审计汇报、H5 与海报复用项目包

这套资料集中保存内容整理、自然口播、可编辑PPT、H5、邮件长图和配图的复用方法。当前口播以经理修改后的18页《内部审计整改流程优化与操作详解》为依据，采用2026-10-20定稿。先确认有效材料，再整理内容和口播，最后设计页面。

写口播时既检查有无遗漏，也检查每句话是否多出了要求。两类事项发起节点有别，不代表后续流程不同；反馈时限不能扩展成审核时限。无明确依据且非必要的解释直接删去，不以工作常识补定规则。

照片和PDF首次按版本全量审阅，将原文、摘要、表格/流程关系及配色版式整理为本地资料索引。后续默认先读INDEX和相关页Markdown，有具体疑点时才回查对应原图；文字、结构、配色分别记录核对状态。实现依据见[知识与方法来源](./workflows/知识与方法来源.md)，不因采用本流程而自动接入云解析服务。

## 下次交给AI的任务模板

> 请先读本项目README、AGENTS和与任务相关的复用规范。我将提供本次有效材料及领导意见。照片或PDF先按材料审阅工作流建立或更新资料索引：首次完整审阅，后续优先读取相关页MD，有具体疑点再回查原图。分别核对文字、结构与配色，保留原文和摘要的区别。核对事实、职责、动作、条件、时点及范围后，再写自然、朴实、可直接朗读的逐页口播。面向有专业经验的员工，不照念PPT，不做基础概念教学，不造新词或虚构案例。
>
> 分别完成内容覆盖与逐句语义核对：连接语不得增加材料未明确的流程差异、前置条件、期限、操作细则或效果。无明确依据且非必要的解释删去；影响必需要求理解的缺口单独提出。来源与核对说明另存，不放入口播。
>
> 若需设计展示，再依照已确认内容制作原生可编辑PPT或适合渠道的H5、海报。按视觉规范选择少量素材，完成渲染和逐页检查。最后同步覆盖当前稿、复用规范与入口，旧稿通过Git历史追溯，当前目录不并列保留待修订版本。

## 复用边界

方法、页面结构、视觉规范和讲述方式可以复用。具体部门、人员、职级、风险条件、金额、时限、比例、评分和实施安排属于案例，必须按新项目有效材料重新确认。

已有机制、当前调整和后续计划分别表达；“原则上”“不建议”“参考”“协助”等限定保留。PPT文字、表格和流程保持可编辑，不增加演讲者窗口。项目文件按用户明确要求纳入本目录，新增材料按当次指定范围处理。
