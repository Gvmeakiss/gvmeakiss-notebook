# 配色与视觉设计要求

适用场景：中国平安内部稽核团队的会议汇报、工作宣导、机制说明类 H5 和可编辑 PPT。

整理日期：2026-10-13。基准为本项目最后交付的 **15 页视觉精修版**，已按同 SHA 构建副本核对实际颜色、字号和对象类型。本文将“最终执行要求”“本稿采用的具体参数”和“已被后续意见覆盖的旧要求”分开记录，便于下次直接复用。

配套内容规范：[02_内容整理与页面规划要求.md](02_内容整理与页面规划要求.md)。

本次参考材料包括《平安内部PPT规范.pdf》及后续提供的《夸克扫描王_背景趋势(1).pdf》。后者用于校正配色、内容呈现和一致性；二者均以用户后续明确的调整要求为准。

## 1. 最终视觉方向

- 保持中国平安品牌方向，以橙色为主强调色，白色为页面底色，搭配浅橙和浅灰组织内容。
- 橙色取历次版本的折中：比早期鲜艳橙稍柔和，又比过淡的版本更有存在感。重点区域使用实橙，辅助区域使用浅色，不把所有区域统一铺成深橙色。
- 配色、内容呈现方式和页面层次一起参考用户提供的扫描范例，不能只换颜色而保留空疏、不协调的版式。
- 页面要有内容密度和明确重点，避免“小字放进大框”形成大片空白，也避免所有内容同样放大、同样强调。
- 框体与表格采用圆滑的圆角处理，整体仍保持内部汇报所需的清楚、克制和整齐。
- 用户指出的某一页是问题样本。同类问题须通篇修正，不能只修样本页。
- 可以根据内容重新设计，不必机械沿用最初的 H5 半成品。

下列色值是**本项目最终实际采用的展示色板**。其中包含经过用户反馈调整的辅助色，不能将整张色板标称为中国平安正式 VI 标准。

### 2.1 按区域套用

| 页面元素 | 推荐组合 |
| --- | --- |
| 主页面 | 白底＋深灰正文＋少量强调橙 |
| 实橙模块标题或流程节点 | `#ED6E40` 底＋白色加粗字 |
| 主要表格表头 | `#ED6E40` 底＋白色加粗字 |
| 次级表头、辅助说明条 | 浅橙或浅灰底＋深灰字 |
| 两列表格中的字段名称列 | 浅灰底＋深灰字；需突出机制名称时可用浅橙 |
| 表格内容区 | 白底＋深灰字＋浅灰细线 |
| 时间、比例、办理变化等重点 | 在浅色底上局部使用强调橙，保留上下文 |
| 页脚 | 白色或浅灰底＋深灰小字，沿用统一橙色细线 |

### 2.2 配色执行规则

1. **实橙底必须配加粗白字。** 标题带、表头、流程节点和说明带都要检查，不能只修改第 5 页。
2. 浅橙、浅灰和白底使用深灰字。浅色背景上不套用白字。
3. 同类元素全稿统一：同一层级的表头、模块标题、节点不要各用一种橙色。
4. 重点采用“主副标题层次＋局部强调色＋字号差异”，不依靠把一整段都涂成橙色。
5. 白色是页面底色，并不要求所有表格和标题条也必须白色。第 4 页最终已采用橙色表头及浅橙机制列。
6. 七步总流程的节点使用同样的颜色和视觉权重。新增亮点在对应展开页说明，不在总览中随意放大某一步。
7. 不把“未来”“后续”等词的机械匹配用于所有场合。例如《后续整改措施表》是材料名称，应保持完整、正常的名称呈现。
8. 本稿最终未采用浅蓝作为主要展示色。没有新要求时，不因早期意见提过浅蓝，就在复用时自行加回。

## 3. 字体、字号和可读性

### 3.1 最终原则

- 默认字体为 **华文楷体**，避免不同页面或中英文混用导致风格跳变。
- 最终稿实际文字均设置加粗。保留必要的字号、颜色和位置层级，不能因为全部加粗就失去重点。
- 早期“标题 22 pt、正文 14 pt”只保留为历史要求。最新要求允许按内容量和显示效果调整，不再机械固定。
- 内容较少的封面、目录、说明页适当增大字号；条件多、职责密集的页面保留较紧凑正文，不一刀切放大。
- 放大文字时同时调整文本框、行距、表头高度、列宽和内边距。不能只改字号。
- 不通过把正文继续缩小来掩盖版式问题，应先调整布局、分组和断行。

### 3.3 字重与断行

- 检查实际渲染后的笔画，不只检查软件中是否勾选“加粗”。
- 本稿对文字使用同色细描边辅助增强字重：普通文字约 `0.3 px`，页脚约 `0.15 px`。这是本次制作的技术做法，不是公司字体规范；其他软件若原生加粗已清楚，不必机械叠加。
- 橙底文字改成白色时，描边也必须同步白色，避免残留深色轮廓。
- 放大字号的对象同步使用约 `1.1—1.2` 倍行距；原有密集正文保留经过检查的行距。导入旧稿后应清除会限制新字号的旧固定行距。
- 不拆开“全国”等完整词语，不留下孤立的末字或标点。优先在完整短语或语义边界处换行。
- 口径、条件、时点不能因换行或版面调整而删减。

## 4. 圆角、表格与版面

### 4.1 圆角规则

- 模块外框、标题条、流程节点采用圆滑处理，避免一整套都是生硬的直角框。
- 表格圆角处理的是**整张表的外轮廓**，内部网格保持清楚、规则的直线。
- 不需要把每一个单元格做成独立圆角块，避免碎片化和网格关系不清。
- 全部同类表格统一检查；第 4 页、第 9 页只是样本。
- 本稿以 `1280 × 720` 的 16:9 画布制作：主要模块外框约 `14 px` 圆角，标题条约 `8—10 px`，流程节点约 `11 px`，表格外轮廓通常 `12 px`，第 4 页大表为 `14 px`。换画布时按比例调整。
- 表格边线通常约 `1 px`，模块外框约 `1—1.2 px`，主标题下橙线约 `2.5 px`。这些属于制作参数，不是品牌强制规范。

### 4.2 表格层次

- 主要规则表应有清楚的表头底色。不能为了白底要求让整张表没有层次。
- 字段表可通过浅灰名称列、白色内容列区分“字段”和“解释”。
- 主表头与次级表头允许不同层级：主表头实橙白字，次级表头浅橙或浅灰深字。
- 表格文字保持可编辑，列宽应围绕实际内容设置。长名称、完整业务词、关键数字不能被边框裁切。
- 表头和正文留出适度内边距。本稿多数单元格左右约 `6—8 px`，主表头上下约 `5 px`。

### 4.3 版面与密度

- 保留统一的主标题、副标题、内容区和页脚位置。同一层级的模块对齐，间距统一。
- 目录应让章节标题、说明、页次形成清楚层次。扩大文字与标题带来改善空疏感，不填入无意义文字或装饰。
- 三道防线、风险等级、状态比较优先横向并列，便于同时阅读和比较。
- 流程图、表格和文字区应服务于内容关系。删除无业务意义的页签、零碎标签和跳转小卡。
- 不增加演讲者窗口、演讲者专用版面或屏幕上的口播提示区。口播使用独立文稿。
- H5 与 PPT 保持内容关系、配色、模块层级的一致性；不要求机械复制每一个像素。

## 5. 可编辑性要求

- PPT 正文必须是原生文字，表格保留原生单元格，流程使用可修改的形状与连接线。
- 不允许把整页 H5 截图作为 PPT 的主体内容。显示效果相近，同时必须能应对经理后续修改。
- 当前最终稿保留 20 张原生表格、204 个单元格；这是本项目的验证记录，不是下次必须达到的数量。
- 本稿表格圆角通过原生角部遮罩和圆角外线实现，表格内部仍可直接编辑。若复用这种做法并移动或缩放表格，应同步调整外围形状，避免圆角错位。
- 跨软件复用时重新检查字体、表格边线和圆角，不仅查看生成代码或格式属性。

## 6. 历次反馈如何落到最终规则

| 历史反馈或中间方案 | 最终保留的要求 |
| --- | --- |
| 初版文字太大、没有重点 | 通过标题层级、局部强调和内容组织建立重点，不把所有文字都放大 |
| 标题 22、正文 14 | 后续允许按页面容量调整；最终普通主标题 26、副标题 16、正文 14—16 |
| 配色改平安橙／浅蓝 | 结合后续扫描参考，最终采用橙、浅橙、灰、白体系 |
| 橙色过于艳丽 | 主填充改为较柔和的折中橙，强调橙主要用于线条和重点词 |
| 改色后又太淡；不必全部深橙 | 同时保留实橙重点与浅色辅助区，避免全淡或全深 |
| 方框过于方正 | 全稿同类模块与表格统一圆角，内部表格网格保持清楚 |
| 字体太纤细 | 使用加粗并检查真实显示，必要时采用同色细描边 |
| 第 2 页留白过多 | 目录增大字号和标题带，重新平衡内容尺度 |
| 第 4 页曾要求全白 | 后续明确要求有底色的表头和圆角表格；保留白色页面底，不再要求每个单元格全白 |
| 第 5 页橙底黑字不清楚 | 所有实橙底文字统一白色加粗，包括表头、模块头和流程节点 |
| 第 9 页表格没有圆角 | 检查并处理全稿同类表格，不只修改第 9 页 |
| PPT 直接放整页图片 | 明确改为原生可编辑文字、表格和流程元素 |
| 按原半成品继续修补 | 允许重新设计，但保持内容逻辑与全稿一致性 |

不再沿用的中间用色：深橙 `#9F4B20`、过淡辅助色 `#FFF1E8`、橙底深字 `#262626`。最终可见文字仅采用深灰、白色、强调橙；PPT 中残留的旧默认样式值不能作为下一次配色依据。

## 7. 全稿视觉验收清单

- [ ] 配色以本色板的角色分工为准，同类元素没有混入多种相近但不同的橙色。
- [ ] 实橙底全部为加粗白字，浅色底使用深灰字。
- [ ] 强调色用于少量关键内容，没有整段或全页失去主次。
- [ ] 稀疏页面字号和内容尺度充足，没有“小字大框”。
- [ ] 密集页面保留完整内容，字体清楚，没有为塞内容过度缩字。
- [ ] 所有表格外轮廓圆滑，表头或字段列有合适的层次。
- [ ] 字号放大后，行距、文本框、内边距、列宽同步调整。
- [ ] 无孤字、拆词、裁切、遮挡、文字压边和不自然换行。
- [ ] 七步总流程及同类模块视觉权重一致。
- [ ] 封面、目录、正文、页脚的字体、颜色和排版一致。
- [ ] 无演讲者窗口、无意义页签或多余装饰。
- [ ] 文字、表格、流程元素可以直接修改。
- [ ] 实际导出后逐页查看，不能只检查用户点名的样本页。

## 8. 下次可直接使用的制作指令

> 请沿用本规范制作内部稽核汇报材料：白底，强调橙 #EA5A26，实橙填充 #ED6E40，浅橙 #FFE3D4，正文 #333333，浅灰底 #F2F2F2，细边线 #C7C9C9。实橙底统一使用加粗白字，浅色底使用深灰字。默认华文楷体并增强可读性，字号按内容容量调整，不机械固定22/14。封面、目录适当放大，密集正文保持清晰。模块与整张表格外轮廓做圆角，内部格线保持规则；主要表头有底色。保持适当内容密度、明确重点和全稿一致性，不加演讲者窗口和无意义页签。PPT必须保留原生可编辑文字、表格和流程元素。完成后逐页视觉审核，检查全稿同类问题。
