# AGENTS.md · windows-tuning/05-games

给 AI 的执行说明。给人看的说明在 [`README.md`](./README.md) 与各游戏子目录的 `README.md`。

**核心纪律：先体检、后动手；每个改动都要能回滚；不猜硬件。**

## 执行协议（以 CS2 为例，其他游戏同理）

| 步 | 动作 | 命令 | 通过判据 |
| --- | --- | --- | --- |
| 1 体检 | 只读体检，不改任何东西 | `pwsh -File cs2/scripts/check-cs2-readiness.ps1` | 退出码 0；输出含硬件、显示、Steam 安装、画面设置、电源、录制、崩溃记录 |
| 2 判瓶颈 | 读体检结论定瓶颈层 | —— | 明确写出"瓶颈在 GPU / CPU / 面板刷新率 / 存储"之一 |
| 3 预演 | `-WhatIf` 看将要改什么 | `apply-cs2-optimizations.ps1 -WhatIf` | 只打印计划，**无任何真实写入** |
| 4 应用 | 真跑 | `apply-cs2-optimizations.ps1` | 每项改动都回读确认，不是"命令成功" |
| 5 重启 | 电源方案 / 层标记需要 | 用户手动 | 重启后再验收，不重启不下结论 |
| 6 验收 | 复跑体检 + 实测帧率 | `check-cs2-readiness.ps1` + 游戏内 | 体检项与预期一致；帧率与 1% low 有数据 |
| 7 回滚 | 不满意就撤 | `apply-cs2-optimizations.ps1 -Revert` | 回到应用前状态，逐项可核对 |

**硬规则**

1. **体检脚本必须只读** —— 不许在里面写注册表、装软件、改设置。
2. **应用脚本必须支持 `-WhatIf` 与 `-Revert`**，且两者都要真实可用（不是占位）。
3. **每项改动都要回读** —— 注册表读实际值、电源方案读 GUID、`powercfg` 读处理器状态；命令退出码只作线索。
4. **幂等** —— 重复跑不应产生重复对象（曾因方案名解析错误**每跑一次就新建一个电源方案**）。
5. **先算天花板再谈优化** —— 面板 60 Hz、核显算力所能到的帧率是上限；突破不了的不要写成"优化项"。
6. **不猜硬件** —— 分辨率、刷新率、显存、核显型号一律从系统读，不假设。
7. **不写没有依据的注册表值** —— 每个值都要能说出"这是官方项 / 实测有效"，否则不加。
8. **`.ps1` 必须 ASCII-only** —— 中文界面匹配用 `\uXXXX` 正则转义，不能直接写中文。

## 脚本契约

| 脚本 | 必须 | 不许 |
| --- | --- | --- |
| `check-<game>-readiness.ps1` | 只读、支持 `-Json`、退出码反映结论 | 写入、安装、修改任何设置 |
| `apply-<game>-optimizations.ps1` | `-WhatIf` 预演、`-Revert` 回滚、逐项回读、幂等 | 不可回滚的改动、静默失败 |

## 新增一款游戏的流程

1. 建 `windows-tuning/05-games/<game>/`（目录名小写 kebab-case）
2. 写 `README.md`：硬件评估 · 瓶颈判定 · 系统优化 · 游戏内设置 · 排错 · 回滚
3. 写 `scripts/check-<game>-readiness.ps1`（只读）与 `apply-<game>-optimizations.ps1`（`-WhatIf`/`-Revert`）
4. 两个脚本都要：ASCII-only、PS 7 与 5.1 双宿主可解析、支持 `-Json`
5. 更新 `README.md` 索引表的「收录的游戏」行，并在「新增一款游戏的流程」保持与本节一致

## 验证判据（怎么算"优化有效"）

| 指标 | 怎么取 | 判据 |
| --- | --- | --- |
| 平均帧率 | 游戏内同一张图、同一段路线 | 与应用前对比，要同条件 |
| 1% low | 帧时间分布尾部 | 比平均值更能反映"卡不卡" |
| GPU / CPU 占用 | 系统监控 | 判定瓶颈层：GPU 满 = 显卡瓶颈；GPU 未满但帧低 = CPU / 同步问题 |
| 刷新率是否真的生效 | 显示设置或体检输出 | 设了 60 但跑 30 属于"设了没生效"，要单独查 |

## 常见坑

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 每跑一次多一个电源方案 | 名字解析没剥尾部 `*` 或括号 | 修解析：先剥 `*`，再只剥最外层括号 |
| `-WhatIf` 却改了系统 | 子脚本没接住 `-WhatIf` | 预演必须真的零写入，逐项确认 |
| 改了注册表但无效果 | 依赖的服务没跑（如 MMCSS） | 读服务状态，不只看值 |
| 帧率没变 | 瓶颈不在被优化的那一层 | 回到第 2 步重新判瓶颈 |

## 纪律

- **动系统前拍快照**（电源方案导出、注册表相关键备份），快照放仓库外的本地目录
- **不把"没测过"写成"有效"** —— 无收益的尝试要标注并回滚，不要留在脚本里
- 截图/日志若含本机路径或账号，不要提交
