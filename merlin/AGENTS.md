# AGENTS.md · merlin

给 AI 的执行说明。给人看的说明在 [`README.md`](./README.md) 与 [`使用指南.md`](./使用指南.md)。

这个项目的核心风险是**泄漏**（节点入口、私人域名、完整备份），改之前先读「红线」。

## 执行协议

| 步 | 动作 | 命令 | 通过判据 |
| --- | --- | --- | --- |
| 1 | 改前基线 | `node --test merlin/tests/*.test.mjs` | 退出码 0 |
| 2 | 改名单 | 只改 `direct-domains.txt` / `proxy-domains.txt` | 一条一行、无注释、无空行、小写、无通配符扩大 |
| 3 | 改生成器 | 只改 `scripts/generate-us-bypass.mjs` | 先跑 `--dry-run` 看输出再真跑 |
| 4 | 复跑测试 | 同上 | 全部用例通过 |
| 5 | 查空白 | `git diff --check` | 干净 |
| 6 | 脱敏 | 搜节点 IP / 私人域名 / 订阅 / 账号 | 0 命中 |
| 7 | 交叉验证 | `node --test shadowrocket/tests/*.test.mjs` | 公开名单与 Shadowrocket 不重叠（最后一个用例守这个） |

**硬规则**

1. **公开名单只放通用域名** —— 私人 API、工作域名、真实节点入口一律不进仓库。
2. **生成器输出永远是私有文件** —— 结果写 `private-output/`（已忽略），不提交。
3. **覆盖保护不能去掉** —— 生成器拒绝覆盖"已经好的一套"，这是防误删的兜底。
4. **失败不落盘** —— 解析失败、非法 JSON、零匹配都必须保持原文件不变，且不回显输入内容。
5. **改名单必须两边一起想** —— `merlin/` 与 `shadowrocket/` 的公开名单不能重叠。

## 文件 → 用途

| 文件 | 用途 | 改动注意 |
| --- | --- | --- |
| `direct-domains.txt` | 119 条通用直连域名 | 合并进 fancyss 域名白名单 |

| `tests/generate-us-bypass.test.mjs` | 14+ 用例 | 见下 |

## 验证判据（用例守什么）

| 类别 | 守的东西 |
| --- | --- |
| 正常路径 | 20 节点 / 11 个 IPv4，保留已有条目，AAAA 本地处理 |
| 去重与覆盖 | 重复域名只查一次；匹配集合可被显式覆盖 |
| 解析语义 | 字面 IPv4 不查 DNS；仅 IPv6 的端点不得混进 IPv4 白名单；多个 resolver 取并集 |
| 失败即停 | 零匹配、任一端点未解析、任意 DNS 错误都失败且**不改文件** |
| 输入防御 | 畸形备份 / base64 / 端口 / 宽泛 IPv4-IPv6 白名单一律安全失败 |
| 特殊地址 | Fake-IP、映射型 AAAA、特殊用途 IPv4 一律拒绝 |
| 泄漏防护 | `--dry-run` 不写文件，且**日志不出现端点、节点名、密钥** |
| 覆盖保护 | 成功时写私有文件，且拒绝覆盖已存在的好名单 |
| CLI 契约 | 输出必须显式给 `--out` 或 `--dry-run`；resolver 可重复 |

## 常见失败怎么定位

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 「zero matches fails」红 | 生成的清单为空仍写了文件 | 恢复"零匹配即失败"分支 |
| 「refuses to overwrite」红 | 去掉了覆盖保护 | 还原保护逻辑，不要为了方便跳过 |
| 「never logs endpoints」红 | 日志里打印了地址或节点名 | 只打印计数，不打印值 |
| 「mapped unsafe AAAA」红 | 只校验了 A 记录 | A/AAAA 都要判 |
| shadowrocket 最后一个用例红 | 两个项目的公开名单重叠 | 任一侧删掉重复项，只留一份 |

## 红线

- **不提交**：真实节点入口与 IP、订阅地址、账号密码、私人/工作域名、完整 fancyss 备份、路由器整机备份
- `private-output/` 已忽略，生成结果只落在这里
- 公开名单条数与本地不同是**预期**：导入前需合并个人例外，不能把公开版当完整私人配置
- 不写"已验证生效"除非做过设备侧联调 —— 静态检查通过 ≠ 插件已加载 ≠ 实际连通
