# 梅林 fancyss 与 Shadowrocket 协同分流

更新：2026-09-23。适用基线为本次操作的 fancyss **3.5.30**。其他插件或版本应先核对对应字段，不要直接恢复不匹配的完整备份。

日常由梅林使用香港节点代理海外流量；需要另一个出口时，Mac / iPhone 开启 Shadowrocket。国内 App、局域网和家庭 NAS 优先直连。外出大陆热点或蜂窝网络由客户端独立分流，不依赖家庭路由器。

这是公开、可复用的规则与操作项目，**不是含账号的整机备份，也不是可直接导入 fancyss 的 JSON**。节点、订阅、私人 API、工作域名和真实入口 IP 不公开。个人环境已应用的完整配置应保留在本地。

## 分流逻辑

- 直连名单覆盖微信、抖音、知乎、番茄、DeepSeek / Kimi、WPS / 文档、NAS、国内视频 CDN、SteamCN 下载等关键服务。
- 代理名单覆盖 OpenAI / Claude 等海外 AI、验证与静态资源、开发工具及海外内容服务。
- 使用大陆白名单模式，未手动指定的流量仍由插件规则和国内 IP 判断处理；此插件的匹配行为不等于逐行执行 Shadowrocket conf。
- 主节点仍为日常香港节点，不因生成美国入口白名单而切换路由器主节点。
- 域名与 IP 绕过针对的是**客户端到美国代理节点的外层连接**，不是让 OpenAI 网站直连。业务流量仍在客户端代理隧道内传输。
- 同时加入入口域名和当时解析得到的 IPv4 `/32`，应对客户端自有 DoH 绕过路由器 DNS 的场景；禁止只填 TLS SNI/伪装站点域名或整个服务商网段。

## 参数基线

这些是本次环境的实际设置，不承诺是所有线路、节点或插件版本的最优值。

| 设置 | 本次值 | 作用与边界 |
| --- | --- | --- |
| 主节点 | 香港节点 | 日常海外网站经香港；语言或网站国家不自动决定节点地区 |
| 运行模式 | 大陆白名单 | 国内直连，海外按插件判断代理，手动名单补充 |
| DNS 分流 | chinadns-ng 智能判断 | 按域名与解析结果区分国内外请求 |
| 国内 DNS | 阿里 UDP、腾讯 TCP、阿里 DoT | 保持现有国内上游组合 |
| 可信 DNS | 代理内 Google TCP、Cloudflare TCP、Google DoT | 保持现有可信上游组合，未改为直出国外 DNS |
| DNS 劫持 | 开启 | 接管插件支持的明文 DNS；不等于接管应用内 DoH/DoT |
| 默认 TCP 代理端口 | `all` | 所有 TCP 端口都遵循分流，不代表全流量代理 |
| UDP 代理 | 关闭 | 未验证任意 UDP/游戏/实时语音都可用 |
| 海外 QUIC 屏蔽 | 开启 | 限制海外 UDP 443，支持回退的应用可尝试 TCP |
| IPv6 代理 | 关闭 | IPv6 不走此代理路径，不承诺海外 IPv6 可达 |
| AAAA 过滤 | 过滤代理 AAAA，保留直连 AAAA | 保留本地直连 IPv6；客户端自有加密 DNS 可能不受此过滤控制 |

不要仅因为新增域名/IP 绕过而开启 IPv6 代理、更换订阅、修改节点认证或关闭证书校验。

## 全部美国节点绕过

生成器从本地备份按节点名称筛选，默认匹配“美国”；名称不含该词的美国节点不会自动按地理位置识别，可用筛选参数调整。提取的是实际 `server`，不是备注、伪装域名或访问目标。

多个节点可能共用入口 IP，去重后 IP 数少于节点数属于正常情况。程序只生成本地文件，不登录路由器、不修改客户端、不上传备份、不自动应用或安排定时任务。

静态结果只覆盖生成时的节点和 DNS 记录。订阅变化、入口轮换、解析失败或更换客户端订阅后应重新核验。DNS TTL 是缓存期限，不是入口稳定性的保证；向不同 DNS 地址请求也不证明存在独立解析路径。

AAAA 只用于观察，不混入 IPv4 白名单。若匹配节点只有 IPv6，先判断路由器 IPv6 代理状态和实际路径，不能通过添加一个错误的 `/32` 解决。

客户端开启后的系统 DNS 可能返回 Fake-IP；生成器会拒绝常见 `198.18.0.0/15` 虚拟地址和明显的本地/私网入口，避免将其误当真实节点。详见[使用指南](./使用指南.md#3-生成全部美国节点入口绕过)。地址格式与这些保护检查不能替代节点供应方信息和网络路径核验。

2026-09-23，本地实例已完成：

- 20 个美国节点入口全部核验，20 个域名对应 11 个唯一 IPv4；名单保存并应用。
- 保存前后备份比对：该阶段仅域名白名单和 IP 白名单变化；节点内容、当前香港主节点及其他设置不变。
- 路由器页面国内外连接检测通过；Mac Shadowrocket 新配置已启用，43/43 个远程规则集加载完成。
- 经客户端本地代理访问 ChatGPT robots.txt、GitHub、百度均返回 HTTP 200；原生规则测试中 ChatGPT 为 PROXY、Kimi 为 DIRECT。

上述是个人本地实例的结果，不代表公开文件已自动部署到读者设备；也不代表所有 20 个节点均经过认证访问、登录对话、长时间流式响应或实时语音测试。iPhone 与外出热点尚未实机验收。
